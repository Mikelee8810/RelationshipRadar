# Android + Shizuku Plan

## Target

Pixel-first Android app.

## Shizuku

Shizuku is a core dependency for enhanced device access.

## Planned integrations

- Contacts
- Call history
- SMS/MMS where permitted
- Notification access for communication apps
- Calendar events

## Future channels

Potential support:

- Messenger
- WhatsApp
- Instagram
- Telegram
- Other apps through notification/activity signals

## Architecture goal

Collect activity locally, normalize it into people, then calculate relationship timers.
