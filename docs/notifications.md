# Notifications

## Default behavior

Use combined reminders plus priority alerts.

## Reminder states

- Due today
- Overdue with visual escalation
- Snoozed
- Paused
- Track only

## Snooze options

- Tomorrow
- Later this week
- Sunday
- Next week
- Custom date

## Backup reminders

Default follow-up:

- Every 2 days
- Maximum one week
- Then stop notifications

The person remains visibly overdue in the app.

## Pause

Pause reminders without changing the contact schedule.

Options:

- 1 week
- 1 month
- Until date
- Indefinitely
